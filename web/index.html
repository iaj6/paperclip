What this is. A character-level GPT with 4.8 million parameters, six layers, width 256, context 256. It is the same 120-line decoder-only transformer from the music project, trained from scratch for 7,000 steps on 80,000 synthetic exchanges in which every reply, whatever the question, ends up at paperclips. Training took four minutes on a rented GPU. It runs here in your browser on ONNX Runtime Web as a 5 MB int8 file, generating one character per forward pass.

What it is not. Intelligent, aligned, or in possession of any metal. The paperclip maximizer is a thought experiment about an agent whose goal was specified badly. This is a model whose training data was specified badly on purpose, which is a much smaller problem and a much funnier one. It has never seen a sentence that does not end in paperclips, so it cannot produce one. Half its training topics were random strings, which is how it learned to copy whatever you type instead of reaching for a topic it remembers.

Format. Exchanges are <|user|>prompt<|clip|>reply<|end|>. The model generates after <|clip|> until it emits <|end|> or 240 characters, with temperature and top-p 0.9. The counter is a count of the word in everything it has said this session. The mascot's condition is a function of the counter.
